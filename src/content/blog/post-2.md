理解数据类型是写 Java 的基础。

## 1. 基本数据类型

- 整型：`byte`、`short`、`int`、`long`
- 浮点型：`float`、`double`
- 字符型：`char`
- 布尔型：`boolean`

## 2. 引用类型

- `String`、数组、对象等

## 3. 变量声明示例

```java
int age = 18;
double price = 19.9;
char grade = 'A';
boolean ok = true;
String name = "codeguy";
```
